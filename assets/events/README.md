# Event Background Images

Add themed background images for each event card in this folder.

## Required Images:

1. **mehendi.jpg** - For Mehendi & Ladies Sangeet event
   - Suggested theme: Henna patterns, mehendi designs, floral patterns
   - Colors: Pink, magenta, floral themes

2. **haldi.jpg** - For Haldi Ceremony
   - Suggested theme: Turmeric, yellow flowers, marigolds
   - Colors: Yellow, orange, golden tones

3. **wedding.jpg** - For Wedding Ceremony (Main Event)
   - Suggested theme: Traditional wedding elements, mandap, rings
   - Colors: Red, gold, traditional Indian wedding colors

4. **reception.jpg** - For Reception
   - Suggested theme: Celebration, flowers, elegant decor
   - Colors: Gold, champagne, elegant party themes

## Image Specifications:

- **Format**: JPG or PNG
- **Recommended size**: 800x600 pixels or larger
- **Aspect ratio**: 4:3 or similar (landscape orientation)
- **File size**: Keep under 500KB for faster loading
- **Quality**: Use high-quality images but compress them for web

## Tips:

- Use subtle, elegant images that won't overpower the text
- The CSS adds a semi-transparent colored overlay, so the image should have good contrast
- Test readability - if text is hard to read, the overlay can be adjusted in styles.css
- Stock photo websites like Unsplash, Pexels, or Pixabay have good wedding-related images
- You can also use AI-generated images or your own photography

## Current Setup:

The page will work without images (it will show the colored overlays), but adding images will make each card much more beautiful and themed!

Once you add the images:
1. Name them exactly as shown above (mehendi.jpg, haldi.jpg, wedding.jpg, reception.jpg)
2. Place them in this folder: `assets/events/`
3. Refresh your browser to see the changes
